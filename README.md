# auto-bot

Телеграм-бот, который на `/start` и на слова-триггеры кидает случайный мем из пула и здоровается. Работает в личке и в группах. Мемы, тексты и настройки правятся командами прямо в Телеге — лезть в файлы и перезапускать бота не надо.

## Что умеет

- случайный мем из пула + приветствие на `/start`;
- реагирует на слова-триггеры (`старт`, `привет`, `start` — список правится командами);
- поддерживает фото, гифки, видео, кружки, стикеры, голосовые и файлы;
- не повторяет один и тот же мем два раза подряд в одном чате;
- пауза между ответами одному человеку, чтобы спамом `/start` бота не загнали во флуд-лимит;
- тумблер «включено/выключено» и статистика;
- битый `file_id` помечает сам и берёт следующий мем.

## Установка

Нужен Python 3.11+.

```bash
git clone https://github.com/podl1z/auto-bot
cd auto-bot

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS

pip install -e ".[dev]"
```

## Настройка

Скопируй `.env.example` в `.env` и заполни:

```ini
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=12345678
DB_PATH=data/bot.db
```

- **BOT_TOKEN** — @BotFather → `/newbot` (или `/mybots` → API Token у существующего).
- **ADMIN_IDS** — твой числовой ID, узнать у @userinfobot. Несколько админов — через запятую.

`.env` в `.gitignore`, в репозиторий он не попадёт.

## Запуск

```bash
python -m bot
```

Бот работает на long polling — никакого белого IP и вебхуков не нужно.

## Команды

Всем:

| Команда | Что делает |
|---|---|
| `/start` | Мем и приветствие |
| `/help` | Короткая справка |

Админам (из `ADMIN_IDS`):

| Команда | Что делает |
|---|---|
| `/addmeme` | Ответь этой командой на медиа — или пришли медиа, подписав его `/addmeme` |
| `/memes` | Листалка по пулу с кнопками `◀️ ▶️` и `🗑 Удалить` |
| `/delmeme <id>` | Удалить мем по номеру |
| `/settext <текст>` | Приветствие. Подстановки `{name}` и `{mention}`, можно HTML |
| `/triggers` | Список слов-триггеров |
| `/addtrigger <фраза>` | Добавить триггер |
| `/deltrigger <фраза>` | Убрать триггер |
| `/cooldown <минут>` | Пауза между ответами одному человеку, `0` — отвечать всегда |
| `/on` / `/off` | Включить или выключить автоответы |
| `/stats` | Статистика |

Перед сохранением `/settext` показывает, как приветствие будет выглядеть. Если HTML кривой — Telegram не примет сообщение, и бот оставит старый текст.

## Группы: обязательно выключи Group Privacy

По умолчанию бот в группе **не видит обычные сообщения** — только команды, реплаи себе и упоминания. Из-за этого триггер на голое слово «старт» в группе не сработает (в личке работает сразу).

Лечится так:

1. @BotFather → `/mybots` → твой бот → **Bot Settings** → **Group Privacy** → **Turn off**.
2. **Перезайти ботом в группу** — кикнуть и добавить заново. Без этого настройка к уже добавленному боту не применится.

## Триггеры и ложные срабатывания

Триггеры матчатся по границам слова: «старт» поймается в «Старт!» и «ну давай, старт», но не в «стартап» и не в «рестарт». Регистр и знаки препинания не важны.

## Тесты

```bash
pytest
```

Покрыты матчинг триггеров и слой базы (дубли, кулдаун, выбор мема без повтора). Сеть не нужна.

## Как всё устроено

```
bot/
├─ __main__.py    точка входа, роутеры, меню команд
├─ config.py      чтение .env и валидация
├─ db.py          SQLite: схема и все запросы
├─ filters.py     IsAdmin, HasTrigger, matches_trigger
├─ media.py       разбор и отправка медиа
└─ handlers/
   ├─ greeting.py основная логика ответа
   └─ admin.py    админ-команды
```

Мемы хранятся как `file_id` Телеграма, а не файлами: картинки уже лежат на серверах Telegram, качать и держать их у себя не нужно. Побочный плюс — `file_unique_id` с `UNIQUE` бесплатно отсекает дубли.

## Если токен утёк

Токен — это полный доступ к боту. Если он попал в чат, коммит, скриншот или чужие руки:

@BotFather → `/mybots` → бот → **API Token** → **Revoke current token**.

Старый токен сразу перестаёт работать, новый вписываешь в `.env`. В код и в репозиторий токен не кладём никогда.
